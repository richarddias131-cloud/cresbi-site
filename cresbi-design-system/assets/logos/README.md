# Logos

Símbolo **Facetado**: losango aberto (o "C") com a pedra de ouro ao centro. Todos os arquivos estão em curvas e não dependem de fonte instalada.

- `cresbi-logo-dark.svg` — Logo horizontal para fundos escuros: tinta `#F2EFE8` (`text`), pedra `#C9A961` (`gold`).
- `cresbi-logo-light.svg` — Logo horizontal para fundos claros: tinta `#15140F`, pedra `#7E6026`.
- `cresbi-logo-vertical-dark.svg` — Símbolo sobre o nome, para espaços quadrados em fundo escuro.
- `cresbi-logo-mono-white.svg` / `cresbi-logo-mono-black.svg` — Uma só tinta (branco / preto), para gravação, carimbo e fundos fotográficos.
- `cresbi-mark-dark.svg` / `cresbi-mark-light.svg` — Símbolo sozinho para favicon, selos e marca-d'água.
- `cresbi-mark-mono-white.svg` / `cresbi-mark-mono-black.svg` — Símbolo em uma só tinta.
- `cresbi-wordmark-dark.svg` / `cresbi-wordmark-light.svg` — Só o logotipo, para espaços muito horizontais.
- `cresbi-avatar.svg` — Perfil do Instagram e do WhatsApp: símbolo centralizado sobre `ground` (#0A0A0B), pronto para recorte circular.
