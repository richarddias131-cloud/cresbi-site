# Tag

Rótulo curto em caixa alta para segmento RFM, categoria ou status.

**Marcação:** `<span class="cr-tag">Campeões</span>`; variantes `--neutral`, `--positive`, `--negative`.

**O consumidor fornece:** uma ou duas palavras.

- O padrão (ouro sobre `gold-soft`) marca o que é estratégico: segmento Campeões, produto foco.
- `--positive` e `--negative` só para status com significado (Em alta / Em risco) — a palavra carrega o sentido, a cor reforça.
- No máximo duas tags por linha de tabela.
