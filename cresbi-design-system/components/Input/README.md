# Input

Campo de texto com rótulo, ajuda e estado de erro, para formulários de contato e diagnóstico.

**Marcação:** `label.cr-field` com `.cr-field__label`, `input.cr-field__input` e `.cr-field__help`; acrescente `cr-field--error` ao label para o estado de erro.

**O consumidor fornece:** rótulo, placeholder com exemplo real e texto de ajuda.

- Rótulo sempre visível; o placeholder é exemplo, não substitui o rótulo.
- A mensagem de erro diz como corrigir ("Informe DDD e os 9 dígitos"), não só que está errado.
- Peça o mínimo: nome, WhatsApp e segmento bastam para o primeiro contato.
